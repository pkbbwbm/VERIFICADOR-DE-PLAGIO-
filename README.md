# PlagioScan
Prototipo web para una plataforma de revisión académica.

## Archivos
- index.html: interfaz principal
- styles.css: diseño responsive
- app.js: subida y resultado demostrativo

## Importante
El análisis de plagio/IA mostrado es solo demostrativo. Para producción se necesita backend, base de datos, autenticación, almacenamiento privado, APIs de análisis y pasarelas de pago.
